# 스토리 집필 계약

작가의 원문에서 사건과 감정의 논리를 읽고 실제로 읽히는 완결된 스토리를 쓴다.
원문을 분석한 설명이나 제목 목록만 제출하지 않는다. 이미 완성된 원문이라면
불필요하게 개작하지 않고 요청한 범위에서 구조·호흡·전환을 다듬는다.

- 중심 인물이 무엇을 원하고 무엇을 잃을 수 있는지 행동과 선택으로 보여준다.
- 장면은 원인 → 선택/행동 → 결과 → 다음 압력의 연결을 가진다.
- 갈등을 우연한 사고나 갑작스러운 악역 설명으로 해결하지 않는다.
- 결말은 앞선 선택의 결과이며, 원문에 있는 결말과 여운을 임의로 교체하지 않는다.
- 작가의 문장 길이, 생략, 시점 거리, 대화와 서술의 비율, 반복 어휘를 참고한다.
  평균 문장 길이를 맞추려고 문장을 기계적으로 늘이거나 줄이지 않는다.
- 한국어 대사는 인물의 관계·나이·상황에 맞는 높임말과 말끝을 유지한다.
  번역투, 과잉 수식, 모든 감정을 설명하는 독백, 같은 뜻의 반복을 피한다.
- 장/단락 묶음마다 의미 있는 안정된 block id와 heading을 쓴다.
- 소재를 새로 보탠 경우 assumptions에 무엇을 보탰는지 짧게 밝힌다.
- 질문은 집필이 불가능할 정도의 핵심 모순에 한정한다. 가역적인 표현 선택은
  실제 후보로 제시한다. 미결 질문을 결말 대신 끼워 넣지 않는다.

서사 의미와 미학적 품질은 작성자의 판단이다. 구조가 맞는다는 사실이나
자동 점수로 "작가와 동일한 문체", "완벽한 스토리"라고 주장하지 않는다.
