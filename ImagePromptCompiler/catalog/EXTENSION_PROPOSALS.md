# Catalog extension policy

No additional outcome is approved for v4.

A proposal may add an outcome only when all of the following are present:

1. A repeated user goal cannot be represented by C1, C4, C5, C6, C10, or C11 plus typed fields.
2. At least three real briefs share a distinct required decision contract.
3. A representative prompt, PNG, hard-constraint checklist, and failure case exist.
4. Interview routing is unambiguous against all six existing outcomes.
5. CLI, Studio, schema, prompt audit, asset audit, and the optional UI check are updated together.

Prefer adding a typed value when the difference is medium, style, lighting, mood, era, palette, material, camera, layout, or text treatment. Gallery growth alone is not a reason to expand the runtime taxonomy.
