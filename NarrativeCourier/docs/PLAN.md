# NarrativeCourier — 남은 PLAN

이 문서는 실제 작품, host와 선택 확장의 남은 qualification을 추적한다. 현재 source와 날짜가 붙은 실행 결과는 [Current](IMPLEMENTATION_STATUS.md), owner별 계약과 구현 연결은 [ANALYSIS](../ANALYSIS.md)를 따른다. 과거 PASS는 다른 source snapshot을 qualification하지 않는다.

## 실제품·선택 확장에 남은 범위

- 실제 원고의 문체·장편 품질, 모델 fidelity와 사람 승인·adoption의 qualification.
- 배포 바이너리·Tauri release, 실제 renderer/provider·MCP/Tauri preview와 release/resume의 host qualification.
- 비POSIX process·잠금 이식, 외부 descendant/process-tree와 capture/fsync 오류의 실제 host 관측.
- 선택 cinematic 연출·rich continuity: source facts·visual reference provenance·contradiction과 stale 검토,
  실제 draft 품질·사람 판단. 기존 다섯 delivery DTO와 NVC 서사 owner를 유지한다.
- 선택 animatic의 실제 작품/연출 검토·다른 host·최대 부하 qualification. 현재 packet 생성과
  downstream 기계 실행 근거를 실제 자산 생성·Human final release로 대체하지 않는다.

Runtime source에는 bounded capture와 lifecycle policy가 있다. 실제 host fault·concurrency qualification은 Current에 날짜와 결과를 기록할 때까지 완료로 취급하지 않는다. [SPEC](SPEC.md)·[ARCHITECTURE](ARCHITECTURE.md)의 public/storage 계약을 임의 확장하지 않는다.
