# Causality / Scenes

A material scene is a transition, not a container of events.

`preconditions → playable pressure/action → dominant turn → postconditions → downstream dependencies`

- Every `SCN-*` declares source lineage and the state it reads/writes.
- A scene may contain many actions; require one dominant dramatic turn, not “one event per scene.”
- Check whether the next material scene is enabled by prior consequences rather than merely following it.
- Detect state teleportation, missing props, impossible travel, knowledge without acquisition, unexplained relationship/power shifts and causal-owner reassignment.
- Label transition risk `LOW`, `WATCH`, or `HIGH`; validate high-risk transitions first.
