# Character State

- Character is evidenced by choice, behavior, interaction and consequence, not biography volume.
- Track material state facets only: goals, commitments, knowledge/belief, relationship/power, physical condition, location/access and irreversible choices.
- The same pressure should reveal distinguishable behavior across major characters.
- A character need not transform. `transform`, `reveal`, `resist`, `collapse`, or `static` are all valid trajectories when supported by the source.
- Dialogue must arise from current state and relationship; do not use dialogue to repair missing causality.
