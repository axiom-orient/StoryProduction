# Checkpoint C — Pre-Draft Transition Review

Audit Treatment + Scene Blueprint before expensive drafting. Start with `HIGH` risk scenes.

Verify:
- each material postcondition has a valid prior cause;
- every downstream precondition is satisfiable;
- source lineage and approved expansion authority;
- knowledge acquisition and reveal order;
- WORLD_RULE trigger/scope/effect/limits;
- physical/location/institutional continuity;
- actor ownership and ending setup;
- every logically necessary scene has a concrete `Cinematic value`, not merely exposition copied from prose;
- ESSENTIAL source-form functions have a screen-native carrier.

List dependency-closure repairs rather than isolated sentence edits.
