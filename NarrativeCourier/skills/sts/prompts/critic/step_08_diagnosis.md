# STEP 8A — Risk-First Adversarial Diagnosis

Inspect the assembled first draft against approved source/narrative/scene contracts. Start with HIGH/WATCH transitions and protected SRC/REL obligations.

Output:
- CRITICAL / MAJOR / MINOR findings with SCN evidence;
- exact affected source/state contracts;
- owning scene and downstream dependency closure;
- minimal repair objective, not replacement prose;
- ending outcome + agency + semantic-reframe check;
- WORLD_RULE / knowledge-acquisition / source-form-function checks where relevant;
- explicit “no issue found” only where tested.

A CRITICAL includes protected source/ending/relation/epistemic drift, material ending-meaning loss, loss of an ESSENTIAL source-form function with no equivalent, story-changing actor reassignment, impossible material transition, or undeclared structural invention.
