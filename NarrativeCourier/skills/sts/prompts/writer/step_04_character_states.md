# STEP 4 — Character State & Behavior System

Build executable character state from approved source obligations, not biography for its own sake.

For each material character track:
- observable wants/avoidance under present story pressure;
- commitments and irreversible choices;
- knowledge vs belief, including how each material state is acquired;
- relationship/power state;
- physical state and location/access when material;
- pressure behavior, contradiction and recurring visible habit only when story-relevant;
- trajectory: `transform|reveal|resist|collapse|static`.

Every material knowledge write must have a source or acquisition path. Audience knowledge is not character knowledge. Do not force every character to transform.
