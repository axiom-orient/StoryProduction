# SceneMotionCompiler — 계약 진입점

기존 AGENTS/외부 독자의 진입 경로를 보존한다. 제품 규범의 정본은 [SPEC](SPEC.md), 정체성은 [IDENTITY_AND_EVOLUTION](IDENTITY_AND_EVOLUTION.md), 책임·실행 구조는 [ARCHITECTURE](ARCHITECTURE.md)다. 이 파일에 별도의 version/command 목록을 복제하지 않는다.

NVC 입력·projection 계약은 [BOUNDARY_NARRATIVE_COURIER](BOUNDARY_NARRATIVE_COURIER.md), producer/consumer schema pin은 [상위 registry](../../integration/contracts/registry.json), native custody release는 [store 분석](../packages/store/ANALYSIS.md)과 해당 schema에 정의한다.

HTML release의 지원·수용 환경은 locked Chromium 및 Darwin/arm64 native custody다. Linux helper 검사로 이를 바꾸지 않는다. source archive는 서명·공증된 독립 `.app` 배포본이 아니다. optional production 후보/OTIO 경로를 추가했어도 사람 승인 없는 영상 release를 허용하지 않는다.
